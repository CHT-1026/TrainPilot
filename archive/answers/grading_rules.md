# 判分规则说明

本文件说明 `answer_bank.jsonl` 中每份答案的判分口径。完整实现见
`../source/scripts/retrieval_eval.py`，校准过程见
`../evaluation/判分器校准记录.md`。

## 一、主指标

**有证据任务成功率** = 答案正确 **且** 引用支持结论。

两项都满足才计通过：只答对但无引用、只引对但答错，都不计。

- **答案正确**：命中题目所问的必要事实（关系、数值、日期、版本、条件）。
- **引用支持**：引用非空、全部来自本轮工具实际检索到的文档，
  且期望依据文档的覆盖率 ≥ 50%。

## 二、答案字段

| 字段 | 含义 |
| --- | --- |
| `qid` | 题目编号，与 `questions/question_bank.jsonl` 严格一一对应 |
| `question` | 题干，与题库完全相同 |
| `answer` | 标准答案 |
| `answer_type` | 答案形态（`relation` / `numeric` / `text` / `json` 等） |
| `expected_doc_ids` | 期望依据文档，必须被本轮检索检出 |
| `evidence` | 逐字证据出处：`doc_id` + `source_file` + `segments[].locator`（行号） |
| `answer_keywords` | 关键实体，供实体级校验使用 |
| `multi_hop_depth` | 需要的推理跳数 |
| `rubric` | 人工审阅口径（`required` / `allowed`） |
| `source_review` | 来源审查状态 |

## 三、自动判分通道

按答案形态选择通道，全部通过才算正确。

### 3.1 结构化金标准（`answer` 以 `{` 开头）

逐字段值与模型答案做**整体比对**，不允许把字段值散落到文本里做子串匹配
（否则无关答案里的巧合数字会误命中）。`null` 字段要求模型显式置 `null`。

### 3.2 文本金标准

按下列通道依次判定，任一成立即算对，且**实体与数字校验对所有通道生效**：

| 通道 | 条件 |
| --- | --- |
| 包含 | 归一化后金标准与答案互为子串 |
| 4-gram 召回 | 归一化后 4-gram 召回 ≥ 0.55 |
| 数字召回 | 关键数字召回 ≥ 0.9 |
| 不可判定 | 金标准本身表达"无法确定/证据不足"，且模型同样表达不可判定并指出证据缺口 |

### 3.3 强制约束（不随通道放宽）

- **关键数字**：金标准含 ≥10 的数字时，模型必须按顺序命中全部关键数字。
  改掉一个数字即判错（4-gram 通道不放行）。
- **人名实体**：金标准提到的人名，模型答案一个都不能少，且不得出现
  语料中查无此人的替代人名。
- **型号**：肯定答案中漏掉关键型号（`LT-C800` 等）判错；
  负类答案中不逐一列举型号属正常，不因此判错。
- **数字精度**：保留一位小数，`3.8 亿` 与 `4 亿` 不等价。

### 3.4 归一化口径

`norm()` 统一数字写法，且**必须保住数字边界**：

- 千分位去逗号：`1,450` → `1450`（多级 `12,345,678` → `12345678`）
- 单位内空格去除：`600 mm` → `600mm`
- 数字之间的分隔符（顿号、斜杠、括号、引号、空格）转为占位符，
  避免 `30、90` 被拼成 `3090`、`LT-R6（1,450 mm）` 被拼成 `lt-r61450mm`

## 四、人名识别

人名实体只取**语料级白名单**（`../evaluation/bank/person_whitelist.json`，
24 人），由语料的结构化人名语境抽取。

不使用"姓 + 1~2 字"的正则扫全文本：中文里「安全委」「范围需」「章包括」
这类跨词短语天然符合该形态，实测会造成 728/1135 道假阴性。

## 五、引用校验

- 引用必须全部来自本轮工具实际检索到的文档（`tool_calls_detail` 中出现的
  `doc_id`），或题干自带的资料编号。
- 期望依据文档的覆盖率 = 被引用的期望文档数 / 期望文档总数，
  需 ≥ 50%。

## 六、模型的可见范围

评测时模型**只能看到**：用户问题、题内会话历史、工具名称/参数/用途、
以及自己实际调用工具取得的原始资料。

模型**看不到**：标准答案、评分证据清单、旧测评报告、其他模型的回答。
`scripts/retrieval_eval.py snapshot` 会在生成工作区时检查并拒绝
把答案文件放进模型可访问的目录。

## 七、复核建议

自动判分覆盖的是**必要事实命中**。以下情形建议人工复核：

- 开放设计题（`answer_type` 非事实型）；
- 同一事实存在多种合法表述（等价单位、路径展开方式不同）；
- 分歧题——两个模型结论不一致时，优先复核。

抽审清单见 `../evaluation/人工抽审清单.md`。
按测评方案第 7 节，单人抽审**不能称"独立双盲评审"**。

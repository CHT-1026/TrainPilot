# TrainPilot

本项目是基于minimind的自学习开发项目，目的是从零开始构建一个轻量级语言模型，为用户提供规模训练中的结果分析。本项目在考虑实用性的同时，更多的是模型构建的学习项目，从零开始对模型的训练过程进行拆分重构，并在原有基础上进行改进。本项目中可能涉及到学习过程的记录，可酌情参考。

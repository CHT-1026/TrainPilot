## 一、总体架构

云平台采用微服务架构，基于 Kubernetes 部署，分为设备接入、数据服务、应用服务与开放 API 四层。

## 二、接入能力

单集群支持 5,000 台设备接入，MQTT 消息吞吐 20 万条/秒，设备离线缓存 7 天。

## 三、数据服务

时序数据存储于 TDengine，业务数据存储于 MySQL，分析任务使用 Flink 与 Spark。

## 四、安全与高可用

通过等保三级认证，支持多可用区部署，核心服务可用性 99.95%，RPO 15 分钟、RTO 30 分钟。
